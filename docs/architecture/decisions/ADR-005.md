# ADR-005 — ClickHouse para sesiones y PostgreSQL para inventario

**Estado:** Sustituido como decisión inicial por [ADR-010](ADR-010.md). **Fuente:** propuesta española pp. 3, 8; caso inglés pp. 3–5 y 9–10.

## Contexto y criterios

El histórico puede alcanzar millones o miles de millones de sesiones, pero el horizonte temporal es desconocido. Consultas principalmente estructuradas y temporales; inventario necesita altas, unicidad y transacciones. El caso ampliado propone base relacional más Elasticsearch por Kafka Connect; la propuesta evita una segunda copia completa del histórico.

## Decisión propuesta

ClickHouse para inserción/consulta analítica de sesiones y agregados; PostgreSQL para inventario editable y datos administrativos. API con adaptadores separados. No indexar todo en Elasticsearch ni conservar el histórico completo en PostgreSQL en la primera versión.

## Alternativas y por qué no ahora

| Alternativa | Ventaja | Motivo para no seleccionarla inicialmente |
|---|---|---|
| PostgreSQL único | Menos motores | La carga analítica de sesiones podría competir con transacciones del inventario; requiere benchmark antes de apostar por ella a escala declarada. |
| PostgreSQL/TimescaleDB | Buen soporte temporal y SQL | Es candidato razonable si escala/consultas medidas lo permiten; aún no hay datos que superen el argumento de almacenamiento columnar propuesto. |
| Base relacional + Elasticsearch del caso | Búsqueda textual y dashboards | Duplica escritura, retención, reconciliación y operación; no hay requisito confirmado de búsqueda de texto que lo justifique. |
| Elasticsearch como único almacén | Búsqueda flexible | Inventario transaccional y unicidad no son su función principal; complica cambios consistentes. |

## Consecuencias y validación

Dos motores y dos modelos de consulta elevan operación y pruebas. Benchmark con dataset y filtros reales, compresión, inserción, concurrencia y retención; reconsiderar Elasticsearch si aparece búsqueda de texto o necesidades de dashboard que ClickHouse no satisfaga.
